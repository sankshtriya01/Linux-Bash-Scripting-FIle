## 📌 About This Repository

This repository contains all lab experiments and the capstone assignment for the course **ENCS356 — Introduction to Linux Bash Scripting Lab**. The experiments are performed on a **KDE Neon Linux** virtual machine running on **VMware Workstation**, covering core Linux concepts from system setup to Bash scripting, file management, and beyond.
